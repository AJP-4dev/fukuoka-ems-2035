# 動画仕様 — 「地図に聞く」福岡市 救急需要の未来地図 2025→2035（福岡版 v1、2026-10-26）

目的: サイト https://ajp-4dev.github.io/fukuoka-ems-2035/ で「何をして、何が分かったか」を、**何も知らない消防職員が一発で理解できる**約6分40秒の無音動画にする。ナレーションなし、音なし。字幕と画面内の注釈だけで伝える。横浜版（~/Dev/yokohama-ems-2035/video）の骨格・契約・美的方向をそのまま継承し、データと章構成だけ福岡に差し替える。

## 技術契約（横浜版 CONTRACT.md を継承。差分のみ記す）
- `src/scene.html`（骨格）、`src/lib.js`（共通基盤）、`src/chapters/ch00.js … ch10.js`。1920×1080・30fps・`window.DURATION`・`async window.seek(t)`・フレームは t の純関数・ネットワーク要求ゼロ・外部フォント禁止（Hiragino Sans / Avenir Next）。
- レンダ: `node scripts/render.mjs --frames 0,300,...`／`--scale 0.5 --start 0 --end 300`／本番 `node scripts/render.mjs --out fukuoka-ems-2035.mp4`。`scripts/render.mjs` の既定 out 名を福岡に変更。コンソールエラー 0。
- **依頼主の確定嗜好（横浜版 v2 で確定）**: 結論カード無し（CPAD=0）／区名は常に「◯◯区」（`wn()`）／点やチップの出現は1秒以内／縦線や順次の枠囲いの演出はしない／URL は出さない／章の切替に一拍（QPAD=0.8）／冒頭8秒・カウンター削除は横浜版 v2 に合わせる（冒頭は輪郭→柱→タイトルのみ、カウンターは字幕に数字を出す）。
- **データ契約の差分（lib.js を直す）**: `DATA.groups=['k','j','w','e1','e2','e3']`（0–6／7–17／18–64／65–74／75–84／85+）。`AGE`・`AGEC`・`AGEL` を6帯に（色: k #9ad0f5, j #bfd7f2, w #3a7bd5, e1 #f4a259, e2 #e63946, e3 #8e3b8f）。`pop[y]`・`disp[y]`・`byAge[y]` の年キーは文字列 `'2025'`…`'2050'`。`disp` は下限シナリオ（L）。`DATA.trend={slopePre,slopeAll,capYear:2040,adjRate,backtest{pred,actual,errPct},ageShare}`、`DATA.series={dispatch,transport,units}`（2013–2024、年キー文字列）、`DATA.nenpo2024={typeDispatch,transportAge,timeSec,nonTrRate}`、`DATA.standard={coef,demandPop,units,current:34,crossYear}`、`DATA.stations[31]{id,name,kind,ward,lon,lat,units,popKey,load{y},perUnit{y|null},arriveEst,note}`、`DATA.rates{k..e3}`、`DATA.city[y]{k..e3,t}`。横浜専用（`hourly`,`nonTr`,`arrive`,`types`,`growthGroup`,`disp24` 等）は無い。`D24 = DATA.series.dispatch['2024']`（100,181）。2025年の基準は `disp['2025']` の区計（100,139）。
- シナリオ倍率（lib.js の `SC`）: `L(y)=Σ disp[y]`、`M(y)=L(y)×(1+slopePre)^(min(y,2040)−2024)`、`H(y)=L(y)×(1+slopeAll)^(y−2024)`。
- 3D／2D 地図の座標変換: `K=100, LON0=130.400, LAT0=33.590, CL=cos(33.59°)`。`hOf(v)=0.4+(v/23000)*7`（最大 博多 22,046 で高さ約7.1）。カメラ初期値は福岡の7区が収まるよう `CAM0` を再調整（dist は横浜 34 → 概ね 26。実装時に `--frames` で確認）。`ORDER_N` の中心は「中央区」。`LOGO` のロックアップは「福岡市 2025→2035 救急需要の未来地図」。`URL_TXT` は削除。
